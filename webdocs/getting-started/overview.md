# Architecture Overview

Toolcoin is a cross-platform app that uses the [Flutter](https://flutter.dev/) framework. If you need to set up Flutter or build the application from source, refer to the official [Flutter Quick Start Guide](https://docs.flutter.dev/install/quick).

::: info Overview Scope
This documentation focuses on the backend logic, services, cryptography, and network clients. UI widgets (in `lib/widgets/`) are excluded.
:::
